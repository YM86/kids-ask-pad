# しつもんしてね (kids-ask-pad)

子ども（幼児〜小学生）と中学生の「なぜ？」に、Web の公的資料で裏づけを取ってから答える 1 問 1 答 Web ツール。

## 特徴

- **2 つのモード**:
  - **こども向け**: ひらがな中心・ふりがな（`<ruby>`）付き・4 文 / 420 字以内・やさしい話し言葉（`〜だよ`）
  - **中学生向け**: ふりがな付き・6 文 / 600 字以内・理由やしくみを順序立てた説明文（`〜です・ます`）
- **質問例プール（計 800 問）**:
  - こども 400 問・中学生 400 問を内蔵
  - 季節と日付に連動した「きょうの なぜ？」ピックアップ（1 問）と、分野別タブ絞り込み
- **音声読み上げ**: Web Speech API（`speechSynthesis`）による文単位ハイライト読み上げ
- **省トークンな「常識回答＋ベリファイ」と「Web検索＋資料照合」の自動切り替え**:
  - 自然・科学・算数・歴史の基礎など普遍的な常識の質問は、Web検索プラグインを使わず回答モデルの知識で回答し、検証モデル（別モデル）の知識で事実関係と読みがなを2重チェック（トークン消費を約1/3〜1/5、API費用を約1/20に削減）
  - 時事・最新統計や、回答・検証モデルが検索を必要と判断した質問は、自動的に公的機関・大学・研究機関優先のWeb検索＋資料照合へ切り替え
- **クリック可能な参照元リンク**: Web検索時は回答の下に参照した公的機関・大学・研究機関などのリンクを表示（知識回答時は「基本知識（AIでチェックずみ）」と表示）
- **プロンプトインジェクション・安全対策**:
  - メタ指示・ロール偽装・システムプロンプト要求の入口遮断、`<question>` タグ隔離、検索演算子サニタイズ、政治・犯罪・性的・自傷の安全フィルタ
- **保護者・管理者画面（ページ最下部「おうちの ひとへ（管理・ログ）」）**:
  - **OpenRouter API キーのローカル保存**（Git 管理外のローカル領域にのみ保存）
  - **使用するモデルの選択**（回答モデル・検証モデル）
  - **表示する文の長さの調整**（こども・中学生それぞれの最大文数・最大文字数）
  - **検索ログ表示**（日時・モード・消費トークン・判定・質問・回答）
  - **パスワード設定**（保護者がロックを設定可能）

## ローカルでの動かし方（2 通り）

### 方法 A：ブラウザーで `index.html` を直接開く（サーバー不要）

1. このフォルダーの [`index.html`](index.html) を Chrome / Edge / Safari などのブラウザーで直接開きます。
2. ページ最下部の **「おうちの ひとへ（管理・ログ）」** を押し、**「0. OpenRouter APIキー設定（ローカル保存）」** に OpenRouter の API キー（`sk-or-v1-...`）を入力して「設定を ほぞん」を押します。
3. API キーや設定・検索ログはお使いのブラウザーの `localStorage` にのみ保存され、そのまま質問・検索・読み上げが動きます。

### 方法 B：付属のローカルサーバー（`server.py`）で動かす（分類＋検索＋裏づけ検証のフルパイプライン）

Python 3（標準ライブラリのみ、追加パッケージ不要）でローカルサーバーを起動できます。

```powershell
python server.py
```

（Windows では `start-server.bat` をダブルクリックしても起動します）

1. ブラウザーで `http://127.0.0.1:8787/` を開きます。
2. ページ最下部の **「おうちの ひとへ（管理・ログ）」** から API キー・使用モデル・文の長さ・パスワードを設定すると、ローカルの `data/config.json`（`.gitignore` 対象）に権限 `600` で保存されます。
3. 質問と回答の履歴は `data/qa/qa-YYYY-MM-DD.jsonl` に保存されます。
